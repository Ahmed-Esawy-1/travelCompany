# EgyVista 🌴

EgyVista is a responsive travel company landing page showcasing tours and destinations across Egypt — from ancient wonders like Cairo and Luxor to coastal getaways like Hurghada and Sharm El Sheikh.

## ✨ Features

- 🖼️ Hero landing section with rotating imagery
- 🗺️ Tour type categories (Ancient Egypt, Beaches, Cruise, Hiking, and more)
- 📍 Top destinations showcase (Cairo, Aswan, Giza, Marsa Alam, and more)
- 🌐 Bilingual support — English & Arabic
- 📱 Fully responsive design

## 🛠️ Built With

- HTML5
- CSS3
- JavaScript (Vanilla)
